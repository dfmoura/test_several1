OBJETIVO
--------
Construir um app web completo de geração de orçamentos para gráfica flexográfica
de etiquetas adesivas em bobina/rolo. Substituir o fluxo analógico de planilha
Excel (.xlsm com VLOOKUPs e macros) por um sistema com:

  1) motor de cálculo determinístico e testável;
  2) catálogos editáveis (papel, máquina, acabamento, etc.);
  3) mapa de facas;
  4) wizard de orçamento com N faixas de quantidade;
  5) visão interna (custos) × visão comercial (proposta ao cliente);
  6) envio por link público para o cliente aprovar/recusar;
  7) autenticação simples + papéis (vendedor / orçamentista / admin).

O Replit deve entregar um protótipo funcional deployável no próprio Replit
(Preview + Deploy). Priorize funcionar de ponta a ponta antes de polir UI.


CONTEXTO DO NEGÓCIO
-------------------
- Produto: etiquetas impressas (flexografia) em BOPP, couchê, térmico, etc.
- Orçamento = especificação do serviço + faca + tabelas de custo + N quantidades.
- Cliente recebe consolidado comercial (sem ver custos internos).
- Matriz/clichê cobrada só no 1º pedido daquele modelo (chave de matriz).
- Arredondamento comercial SEMPRE para cima (serviço em múltiplos de R$ 10;
  matriz em múltiplos de R$ 1).

CAMPOS DE ENTRADA DO ORÇAMENTO
------------------------------
Cabeçalho:
  - data, cliente (parceiro), vendedor, observação interna

Especificação:
  - medida / tamanho (via faca ou texto)
  - largura_papel_cm
  - puxada_cm (da faca)
  - cores: 0 | 1 | 2 | 3 | 4 | 4V | 5 | 6 | 7 | 8
  - papel (catálogo)
  - acabamento (catálogo)
  - qtde_modelos (default 1)
  - qtde_colunas
  - etiq_por_rolo
  - tubete: 1" | 1" 1/2 | 3"
  - Z (da faca; pode ser null em casos especiais)
  - faca_id (mapa)
  - repeticao (da faca)
  - maquina_roda_servico + maquina (grupo de custo)
  - imposto_pct (12–25)
  - matriz: SIM | NAO
  - coluna_rebobinacao (default 1)
  - rpm (default ~1300)
  - tipo_troca_produto

Faixas (N):
  - quantidade (etiquetas)
  - comissao_pct (pode herdar)


MOTOR DE CÁLCULO (espelhar planilha — NÃO inventar fórmulas)
------------------------------------------------------------
Produção (por quantidade Q):
  metragem_linear = (puxada/100) * Q / qtde_colunas
  hora_maquina = (metragem_linear / rpm) + 1
  hora_troca_produto = tempo_parada_h * (qtde_modelos - 1)
  hora_troca_bobina =
      se metragem_linear < 1000 → 0
      senão (((metragem_linear/1000) - 1) * 5) / 60
  metragem_m2 = CEILING( (Q * largura_papel * puxada) / 10000 , 0.1 )
  qtde_rolos = Q / etiq_por_rolo

Perdas:
  - perda_acerto: lookup por cores (tabela); regras especiais 4 / 4V / 5+ 
  - perda_acabamento: lookup
  - perda_troca_bobina_m2:
      se metragem_linear ≤ 1000 → 0
      senão (5 * (largura_papel - 0.75) * qtde_colunas / 100) * (metragem_linear/1000)

Custos (R$):
  valor_papel = (metragem_m2 + perda_acerto + perda_troca_bobina) * preco_papel_m2
  valor_maquina = hora_maquina * tarifa_hora(maquina, cores)
  valor_troca_produto = hora_troca_produto * tarifa_hora(...)
  valor_troca_bobina = hora_troca_bobina * tarifa_hora(...)
  tinta =
      se cores=0 → 0
      senão se (metragem_m2 + perda_acerto) ≤ 30 → cores * 10
      senão (metragem_m2 + perda_acerto) * 0.40
  acabamento = preco_acabamento_m2 * (metragem_m2 + perda_acerto + perda_acabamento)
  rebobinacao = ((metragem_linear * qtde_colunas) / coluna_rebobinacao / 1000) * preco_rebobinacao
  tubete = qtde_rolos * preco_tubete
  valor_caixa = qtde_caixas * preco_caixa
  valor_servico = soma(papel..caixa)

Matriz (se Matriz=SIM e ainda não cobrada):
  largura_matriz = largura_papel * qtde_colunas
  valor_matriz_raw =
    ((((Z * 3.175)/10) + 4) * (largura_matriz + 4) * qtde_cores) * valor_cm2
  valor_matriz = CEILING(valor_matriz_raw, 1)
  chave_matriz = hash estável de
    {cliente, medida, z, cores, largura_cm, colunas}
  Se chave já existe em matriz_cobradas → não cobrar de novo.

Comercial:
  comissao = valor_servico * (comissao_pct/100)
  imposto = valor_servico * (imposto_pct/100)
  servico_com_encargos = valor_servico + comissao + imposto
  valor_etiqueta_apresentado = CEILING(servico_com_encargos, 10)
  total_faixa = valor_etiqueta_apresentado + valor_matriz
    (matriz tipicamente só na 1ª faixa / 1º pedido)

IMPORTANTE:
- Intermediários podem usar float (como Excel).
- Teto comercial (ceiling) só no fechamento.
- Parâmetros (5 min/troca bobina, R$/caixa, cm² matriz, arredondamentos)
  DEVEM ser configuráveis no catálogo — nunca hardcoded no meio do motor.
- Antes de inventar regra nova, preserve a lógica acima. Se ambíguo,
  marque TODO de negócio e proponha — não "corrija" o preço em silêncio.

MÁQUINA DE ESTADOS DO ORÇAMENTO
-------------------------------
RASCUNHO / CALCULADO  → editável, excluível ("Em preparação")
        │ enviar para aprovação
        ▼
ENVIADO / VISUALIZADO → imutável ("Enviado p/ aprovação")
        │
        ├─ APROVAR  → APROVADO   (travado; link inativo)
        └─ RECUSAR  → REPROVADO  (editável de novo → reenvio)

API autenticada (exemplos):
  POST /api/auth/login
  GET/POST /api/orcamentos
  GET/PUT  /api/orcamentos/:id
  POST     /api/orcamentos/:id/calcular
  POST     /api/orcamentos/:id/enviar-aprovacao
  GET      /api/orcamentos/:id/destinatarios-aprovacao
  CRUD     /api/catalogo/*
  CRUD     /api/facas
  CRUD     /api/parceiros

API pública (throttle):
  GET  /api/publico/orcamentos/:token
  POST /api/publico/orcamentos/:token/decidir
       body: { acao: "APROVAR"|"RECUSAR", nome_confirmacao, faixa_escolhida? }


PRINCÍPIOS DE PRODUTO (obrigatórios)
------------------------------------
1. Custo real + perdas + setup + overhead + imposto + comissão — nunca "no olho".
2. Parametrizado: mudar preço no catálogo NÃO exige mudar código.
3. Auditável: snapshot no save; reabrir mostra os mesmos números.
4. N faixas de quantidade no mesmo orçamento.
5. Separar cálculo interno × proposta comercial.
6. Arredondar comercial sempre para cima.
7. Ferramental (matriz) cobrado uma vez por chave.
