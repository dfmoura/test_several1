LEGENDA
-------
  PK   = chave primária
  FK   = chave estrangeira
  UQ   = único (unique)
  IDX  = índice
  SD   = soft delete (deleted_at)
  *    = nullable
  →    = relação (N→1 ou 1→N)

Invariantes de domínio
----------------------
  · Identidade dupla: id BIGINT + codigo legível (EMP-, PAR-, USR-, ORC-, REL-, BEM-, CFIN-)
  · Multi-empresa: empresa_id + header X-Empresa-Id
  · Usuário nasce de colaborador (parceiros.papel_colaborador)
  · Soft-delete / inativar — sem apagar histórico
  · BEM ≠ G10: bens_patrimoniais = ativo físico; orc_catalogo_maquinas = tarifa ORC
