# Proposta Comercial — ERP RLP × TRIGGER

Proposta comercial profissional, pronta para aceite e impressão em PDF.

## Abrir

```bash
# Opção 1 — abrir direto no navegador
xdg-open index.html

# Opção 2 — servir localmente
python3 -m http.server 8037
# → http://localhost:8037
```

## Gerar PDF

1. Abra `index.html` no Chrome / Edge / Firefox.
2. Clique em **Imprimir / Salvar PDF** (ou `Ctrl+P`).
3. Destino: **Salvar como PDF**.
4. Margens: **Padrão** (o CSS já usa A4 com margens de 14 mm).
5. Ative **Gráficos de fundo** / *Background graphics* para manter cores da marca.
