2. A API DE BUSCA DE INSCRICAO ESTADUAL (SINTEGRA)
================================================================================

Sim: a SintegrAPI JA oferece essa API. Nao e preciso "criar do zero" —
o produto existe e esta documentado. Voce integra via HTTP GET.

Nome do produto:
  API Sintegra — Consulta de Inscricao Estadual por CNPJ

Para que serve:
  - Validar IE no cadastro de clientes/fornecedores
  - Enriquecer CNPJ com inscricoes estaduais e situacao na UF
  - Automatizar o que hoje e feito manualmente em portais estaduais
  - Integrar em ERP, CRM, e-commerce B2B, fiscal e compliance

Endpoint (versao atual documentada):
  GET https://api.sintegrapi.com.br/consultas/v2/sintegra/{cnpj}

Autenticacao:
  Header obrigatorio:
    x-api-key: SUA_CHAVE_DE_API

  A chave e gerada no dashboard apos cadastro.
  NUNCA versionar a chave em repositorio Git.


--------------------------------------------------------------------------------
2.1. Entrada (parametros)
--------------------------------------------------------------------------------

OBRIGATORIO
  cnpj  (path)  CNPJ com ou sem pontuacao (completo)

OPCIONAIS (query string)
  uf               UF especifica (SP, RJ, MG...) OU "BR" para todas as UFs
                   Se omitido, a API pode usar a UF de emissao do CNPJ.
  cache            Idade maxima (em dias) para aceitar cache. Padrao: 7
  cache_strategy   CACHE_SE_EXISTIR | CACHE_PREFERENCIAL |
                   SO_ONLINE | ONLINE_PREFERENCIAL (padrao)
  error_fallback   true/false — usar cache se a consulta online falhar
  endereco         true/false — incluir endereco da IE (1 credito extra)


--------------------------------------------------------------------------------
2.2. Exemplos de chamada
--------------------------------------------------------------------------------

Consulta em uma UF (ex.: Sao Paulo):

  curl -G "https://api.sintegrapi.com.br/consultas/v2/sintegra/15436940000103" \
    -H "x-api-key: SUA_CHAVE_DE_API" \
    -d "uf=SP" \
    -d "cache_strategy=ONLINE_PREFERENCIAL"

Consulta em TODAS as UFs (uf=BR):

  curl -G "https://api.sintegrapi.com.br/consultas/v2/sintegra/15436940000103" \
    -H "x-api-key: SUA_CHAVE_DE_API" \
    -d "uf=BR"

Consulta com endereco da IE:

  curl -G "https://api.sintegrapi.com.br/consultas/v2/sintegra/15436940000103" \
    -H "x-api-key: SUA_CHAVE_DE_API" \
    -d "uf=SP" \
    -d "endereco=true"

--------------------------------------------------------------------------------
2.4. Observacoes importantes da API
--------------------------------------------------------------------------------

- uf=BR consulta varias UFs em background; cobra 1 credito por UF
  e pode demorar mais.
- Dados dependem da disponibilidade dos Sintegras estaduais (fontes
  oficiais). Nem todos os campos existem em todas as UFs.
- Cache compartilhado reduz latencia e falhas; a estrategia padrao
  recomendada e ONLINE_PREFERENCIAL.
- endereco=true cobra 1 consulta extra por requisicao (mesmo com uf=BR,
  e 1 extra no total, nao 1 por UF).

================================================================================
4. COMO USAR NA PRATICA (PASSO A PASSO)
================================================================================

1) Acessar https://sintegrapi.com.br e cadastrar / escolher plano
   (Free Tier ja permite 10 consultas/mes para testar).

2) Gerar a chave no dashboard (x-api-key).

3) Chamar o endpoint:
     GET /consultas/v2/sintegra/{cnpj}?uf=XX
   com o header x-api-key.

4) Ler o array inscricoes_estaduais na resposta JSON e mapear no seu
   sistema (cadastro, ERP, validacao fiscal etc.).

5) Tratar erros e indisponibilidade dos portais estaduais
   (cache_strategy, error_fallback).

6) Monitorar consumo de creditos conforme o plano contratado.
