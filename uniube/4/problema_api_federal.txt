Descrição

Assunto

Incidente de inconsistência / atraso de replicação entre o PNCP (consulta oficial) e a API de Dados Abertos do Compras.gov.br (módulo Contratações — Lei 14.133/2021).


Resumo

A contratação abaixo está publicada e consultável no PNCP, porém não é retornada pela API Dados Abertos do Compras.gov.br — nem por busca direta por número de controle PNCP, nem por listagem filtrada por unidade, modalidade e período de publicação. Isso impede a ingestão automática por sistemas que consomem exclusivamente o endpoint de Dados Abertos.

3) Lacuna sequencial

Para o CNPJ 18431312000620 / ano 2026, a série via Dados Abertos (consulta por ID) está ausente a partir do sequencial 000335 em diante (000335 a pelo menos 000345 = 0 registros), enquanto o PNCP já contém ao menos o sequencial 000341.


Comportamento esperado

• Contratação divulgada no PNCP deve tornar-se consultável na API Dados Abertos em prazo operacional razoável e documentável.

• No mínimo, a busca por numeroControlePNCP no endpoint 1.1 deve retornar o registro correspondente após a divulgação no PNCP.


Comportamento obtido

• PNCP: registro disponível.

• Dados Abertos: registro inexistente (vazio), apesar de filtros corretos e de registros anteriores da mesma UASG estarem presentes até 23/07/2026 (sequencial 000334).


Impacto

Sistemas integrados que consomem a API Dados Abertos (endpoint de contratações PNCP 14.133) ficam defasados em relação ao portal PNCP. Editais ativos — inclusive com prazo de propostas ainda aberto — deixam de ser capturados automaticamente, com risco operacional e de transparência para quem depende dessa API como fonte de sincronização.


Solicitação

1) Verificar a carga/replicação do módulo Contratações PNCP 14.133 na API Dados Abertos para a UASG 926922 a partir de 24/07/2026.

2) Incluir/disponibilizar o registro 18431312000620-1-000341/2026 (e, se confirmada a lacuna, os sequenciais intermediários/posteriores ainda ausentes).

3) Informar, se possível, a causa (fila de carga, falha de sincronismo, filtro interno, atraso operacional) e o prazo estimado de normalização.

4) Se houver SLA ou periodicidade oficial de atualização PNCP → Dados Abertos, favor indicar referência documental.
