Automação de Consultas HTTP

Interface local para iniciar e acompanhar requisições HTTP sequenciais em ambiente Docker. Uso demonstrativo e educacional.

Respostas HTTP (incluindo 200) indicam apenas sucesso técnico da requisição. Não comprovam que o mecanismo de busca contabilizou a pesquisa como válida.
